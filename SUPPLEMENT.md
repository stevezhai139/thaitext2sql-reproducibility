# ThaiText2SQL: supplement to the paper

The paper has a six-page limit. This file holds part of what the paper points to as "in the artifact": the full list of limitations, errata for the next suite version, the tables and figure that the revised paper no longer prints, and design details moved out of the paper. Other pointers resolve to repository files: extension Wilson intervals (`results/ext/tables/ext_accuracy.csv`), counts under the original key (`results/rc1/rev_numbers/decomposition.csv`), stored-values results per model, arm and language, local models exploratory (`results/rc1/h1h4/rc1_accuracy.csv`, `results/rc1/h1h4/rc1_silent.csv`), per-item alternative keys and normalizations (`suite/k3n_suite_v1.3n_oct.tsv`), the prompt string (`harness/runner.py`), the scale-up generator (`harness/scale_ecommerce.py`), the extension family decisions (`suite/ext_inputs/ext_decisions_2026-10-14.json`), and the chat-check protocol (preregistration AMENDMENT-8). Numbers come from the files named below or from the preregistration (`prereg/preregistration_FROZEN.md`, including its dated addenda). The exception is the translation-agreement figures in Section 1, item 6, which come from the two rating sheets (`results/annotation_sheet_A.xlsx`, second annotator; `results/annotation_sheet_B.xlsx`, original translator). `harness/score_annotation.py` prints the observed agreement and Cohen's κ, and PABAK is 2 × observed agreement − 1. The values without Q27 were recomputed from the same sheets during the revision and are not stored in a results file. Re-grading the logs with the released grader and key reproduces every graded count in the paper exactly; planner costs (paper Section V-C) re-derive only up to PostgreSQL's ANALYZE sampling.

## 1. Limitations (full list)

The paper's Section VII keeps the core of this list.

1. **Scope.** This is a curriculum-scoped instrument study over two schemas from one database course. The 40-item extension uses the President schema only and its items were chosen after the August 2026 results, so extension results are descriptive. With n = 60 per language the per-cell Wilson intervals are wide; inferential claims rest on paired exact McNemar tests: within model for the English-Thai gap (Holm-corrected across six models) and for Thai accuracy with and without stored values (Holm-corrected across the three proxies only), and between the exploratory typhoon2-8b/llama3.1:8b pair (uncorrected); the stored-values gap share carries an item-bootstrap 95% interval. The pooled 100-item reading is a preregistered sensitivity whose p values are uncorrected and which does not upgrade any claim.
2. **Vendor drift.** Every generation is logged with its model identifier and timestamp. Two identifiers, `claude-sonnet-5` and `gemini-3.6-flash`, are undated aliases, so the identifier lock cannot reveal a silent update; their provider metadata was identical before and after the October 2026 collection (`results/rc1/provenance_before.json`, `results/rc1/provenance_after.json`), which does not rule one out. In October the local weights were also locked by Ollama digest; the August collection did not record digests.
3. **August to October consistency.** On the 59 core items asked identically in both collections (Q27 was repaired), with both collections graded under the revised key (v1.3n; base arm), majority-correct items went from August to October as follows, with the number of items that changed correct to wrong and wrong to correct in parentheses (`results/rc1/consistency/consistency.csv`; descriptive, no test):

   | Model | English | Thai |
   |---|---|---|
   | claude-sonnet-5 | 58 → 57 (1, 0) | 53 → 54 (1, 2) |
   | gpt-5.4-mini | 55 → 56 (0, 1) | 48 → 50 (0, 2) |
   | gemini-3.6-flash | 56 → 56 (0, 0) | 53 → 56 (0, 3) |
   | qwen2.5-coder 7B (exploratory) | 38 → 39 (0, 1) | 25 → 25 (0, 0) |
   | llama3.1 8B (exploratory) | 32 → 34 (0, 2) | 23 → 23 (0, 0) |
   | typhoon2 8B (exploratory) | 21 → 22 (1, 2) | 17 → 17 (0, 0) |

   The submitted paper's August counts used the original key on all 60 items; `results/rc1/rev_numbers/decomposition.csv` gives both. The local models decode at temperature 0 with a fixed seed on byte-identical prompts, so for them this is a re-run check, not an independent replication. It is not an exact re-run either: the local models were installed again before the October collection, with no August digests to compare (item 2), and the October base calls ran in a different order, interleaved with the stored-values arm, which changes Ollama's prefix-cache state; the preregistration names this as a possible source of changed answers (deviation D-8).
4. **Free apps and their proxies.** The free-app-to-API mapping is a documented tier-class proxy, not a claim of interface identity: chat products add system prompts, clarifying questions, explanations, and multi-turn use that the API does not replicate.
5. **Chat-app consistency check.** The check is single shot and single turn on one date (21 October 2026). Form A places the API system prompt inside a user message, so it does not reproduce the API condition exactly. Form B is an instructor-written student-style prompt, not one written by students, and its coding records whether a wrong reply flags stored values, asks back, or gives no warning, but not how a dialogue continues. All 84 chats were entered between 10:43 and 13:21 ICT, cell by cell across the three apps. Silence codes come from two blinded coding rounds at least three days apart (agreement 49 of 54 replies, Cohen's κ 0.78; the five disagreements were reconciled with written reasons, `results/chat/silence_final.tsv`); the style of a reply may reveal its app, so the blind is procedural. The apps' model labels differed from the proxies' identifiers: Claude.ai showed 'Sonnet 5.5 medium' and the Gemini app 'Gemini auto' on every chat, and ChatGPT showed none (`results/chat/log_index.tsv`). These labels are not pinned versions: as the preregistration declares (AMENDMENT-8 §12), the apps can change model or routing without notice, and a free plan may switch to a smaller model under quota; no chat showed a rate-limit or model-switch banner, which does not rule out a silent switch. In a blinded audit of the 14 wrong value-grounding replies (app, form and classifier class hidden), coded on 21 October 2026 by the author, who had also entered the chats that day, the grounding classifier agreed with the author's codes in 8 (57%, Cohen's κ 0.24); the classifier, which the preregistration makes primary, counts 8 grounding failures and the author 11, mainly because it skips literals inside function-wrapped columns. By the author's codes, Claude.ai has grounding failures in 4 of 10 Form A and 1 of 10 Form B cells, among them Q14 and Q42, which its proxy answered wrongly in 4 of 5 Thai runs each; Q42 is a proxy grounding failure only by the classifier, so with the author's codes on both sides Claude.ai and its proxy share only Q14 (`results/chat/vg_audit_agreement.tsv`, `results/rc1/audit/agreement_cells.csv`). On the eight other Form B items (paper Section IV), ChatGPT, the Gemini app and Claude.ai answered 8, 7 and 7 correctly. The two wrong replies (Gemini app Q41, Claude.ai Q50) returned wrong non-empty results and were coded silent; they are among the wrong Form B replies in the paper's silence counts. Correctness matched the same-vendor proxy's October schema-only Thai majority on 6, 6 and 8 of the 8 items: ChatGPT was correct on both items its proxy failed (Q25, Q50); the Gemini app was correct on Q50, which its proxy failed, but wrong on Q41, which its proxy passed; Claude.ai failed Q50, as its proxy did (`results/chat/report/chat_summary.tsv`, NONVG rows; per cell, `results/chat/report/chat_cells.tsv`).
6. **Translation validation.** A second bilingual annotator (not an author) rated the comprehension clarity of the 60 Thai phrasings of the submitted suite and confirmed all nine core stored-value items (Q48, whose question names no stored value, was also marked); the original translator rated clarity independently. Observed agreement is 0.90, Cohen's κ 0.21 (depressed by skewed marginals: 53 of the 60 items were judged clear by both raters) and PABAK 0.80; dropping the repaired Q27 leaves all three unchanged at two decimals. Seven items were flagged unclear by at least one rater (one, Q13, by both); their English-to-Thai accuracy gap, pooled over all six models (majority of five runs; the three local models are exploratory), is +2.4 points against +12.3 for the other 53 (`results/rc1/paper_numbers_oct.txt`). The repaired Q27 wording and the 40 extension items were translated by the author and cross-checked with AI assistance by executing alternative readings, without a second human rater; a back-translation study with additional raters remains future work.
7. **One SQL dialect.** Every query is graded on PostgreSQL 16.9, as in single-dialect predecessors.
8. **Thai-adapted weights.** The Thai-adapted model runs from a community quantization (mradermacher, Q4_K_M) of a now-inaccessible third-party repository labelled as Typhoon 2, whose identity with the official release we could not verify; it is quantization-matched to its base pair, `llama3.1:8b`.
9. **Output cap and re-asks.** On the 40 extension items the 1,024-token output cap bound `claude-sonnet-5`: five responses (four cells) held only reasoning and were re-asked, and 14 graded answers (12 Thai, 2 English, including two re-asked cells) hit the cap mid-query and count as loud failures (`results/rc1/rev_numbers/ext_claude_truncation.csv`; re-ask counts and the 567-token maximum: preregistration addenda of Gate 3 and revision set 2); in three Thai cells (X07, X17, X37) every run not cut off is correct (2 of 2, 1 of 1, 2 of 2), so the cut-off runs decide those majorities (non-preregistered sensitivity, recorded in the preregistration cap addendum; `results/rc1/rev_numbers/summary.txt`, item 4). The 60 core items were unaffected (at most 567 output tokens), but Claude's extension and pooled Thai gaps may be overstated by up to three items (X17 and X37 are correct only in English; X07 is wrong in English as well). Re-asking also filled one `gemini-3.6-flash` and three `typhoon2-8b` cells (120-second timeouts), and cells answered only on re-asking may favor shorter answers; two `typhoon2-8b` Thai runs of X28 timed out on every attempt, so `typhoon2-8b` is left out of the extension analyses and its extension counts come from 398 of 400 runs.
10. **Execution grading.** Execution grading accepts wrong code that reproduces the key on our data and rejects sound code the key does not anticipate, so silent-wrong counts are relative to the key; a blinded code-reading audit is future work.
11. **Instrument, not classroom.** Measuring how often students submit silently wrong SQL, and whether teaching verification changes that, needs a term of a Thai-taught section of the course and ethics approval.

## 2. Errata for the next suite version

Items 1–3 are the defects that the paper's Section III-C names; item 4 repeats the Q48 note of Section III-B.

1. Two items refer to centuries. They follow Western numbering with colloquial bounds (the nineteenth century is 1800–1899) but leave this implicit; on the course data the strict bounds (1801–1900) return the same rows.
2. Nine items carry a tiebreak clause. Seven of them name the key but not the direction; for two of the seven (Q47, Q51) the Thai wording gives the direction and the English does not. The revised key accepts each reading.
3. Further wording errata, left unfixed in this version because the models had already seen these items (`suite/CHANGELOG_v1.2_to_v1.3.md`, errata section; preregistration C4): the Thai wording has typos in Q07 ("ขื่อ" should read "ชื่อ"), Q33 ("โดยฉลี่ย" should read "โดยเฉลี่ย") and Q43 ("ประเภภ" should read "ประเภท"); the Thai wording of Q35 writes the table identifier as "President_Holding" instead of `PresidentHolding`; in Thai, Q37 should add "ระดับสมาชิก (MembershipTier)", Q45 should read "ภูมิภาค" for "ภาค", Q18 should add "ครั้งแรก", Q47 should reword "เกิดก่อนใครที่สุด", Q33 should add "ต่อสมัย", and Q08 should add a "(แสดง …)" clause and its year convention; Q46 and Q49 should state the unit (per term or per person), Q52 the grain, Q57 the rounding, and Q39 and Q54 the month format; Q25 should reword its English parenthetical as "(one term ended before another began)" and give the same hint in Thai, Q55 should name the category in its bracket, and Q02 should add a tiebreak. Q41's threshold (more than 100 orders) does not exercise `HAVING`, because every channel has 282–317 orders. The same section lists known defects in the course data, such as vice-president and runner-up names that do not match the President table and three repeated `OrderID` values; every answer key is relative to the database as distributed.
4. Q48 compares the placeholder `'None'`, which the database no longer stores because missing values are encoded as NULL, so that conjunct does not affect its answer; Q48 stays in the value-grounding set under the preregistered syntactic rule.

## 4. Design and setup details moved from Sections III-IV

- **Course data (Section III-A).** The President schema holds 45 presidents, 9 parties, 49 office-holdings, and 49 marriage records, one of them a no-spouse placeholder; the Ecommerce schema is one table of 38 columns and 2,390 retail transactions.
- **Translation rule (2) (Section III-B).** Rule (2) of the translation protocol follows how, in the author's teaching experience, Thai students mix languages over an English-keyed schema.
- **Effect sizes (Section IV).** Effects are reported in percentage points, not standardized effect sizes.

## 5. Further readings

Other courses, in Thai and beyond, are invited to take their own readings with this instrument by pull request, carrying execution-validated gold queries and run logs.
