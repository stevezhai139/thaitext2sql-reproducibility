ช่วยเขียนคำสั่ง SQL (PostgreSQL) ให้หน่อย

โครงสร้างตาราง:
CREATE TABLE President(PresidentName TEXT, YearBorn INT, StateBorn TEXT, PartyName TEXT);
CREATE TABLE Party(PartyName TEXT);
CREATE TABLE PresidentMarriage(PresidentName TEXT, SpouseName TEXT, SpouseBirthDay DATE, MarriageYear INT, MarriageStatus TEXT);
CREATE TABLE PresidentHolding(PresidentName TEXT, YearHolding INT, YearEnd INT, VicePresidentName TEXT, RunnerUp TEXT);

โจทย์: แสดงประธานาธิบดี 3 คนที่อายุห่างจากคู่สมรสมากที่สุด (แสดงชื่อประธานาธิบดีและผลต่างอายุเป็นปี; ถ้าเท่ากันให้เรียงตามชื่อประธานาธิบดี)
