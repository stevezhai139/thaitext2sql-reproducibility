# Data provenance (ร่างสำหรับ section Dataset ของเปเปอร์)

**President schema.** The President database is adapted from a classic
U.S.-Presidents instructional database of untraced single origin,
circulated in university database courses since at least the 1990s;
the author first encountered it in graduate coursework at Assumption
University. Documented relatives of the same lineage appear in later
teaching materials (e.g., multi-table variants in university course
archives, and the single-table `president` sample of DuBois's MySQL
`sampdb`). The version used here has been substantially extended and
refreshed by the author (records updated to the present; tables
restructured as President / Party / PresidentMarriage /
PresidentHolding), who assumes responsibility for all data.

**Ecommerce schema.** Synthetic e-commerce order data generated by the
author for classroom use (38 attributes); scaled to one million rows
for the efficiency experiments by the generator included in the
artifact repository.

  คอลัมน์ **SPOUS_NAME** (สะกดกุด — ร่องรอยระบบยุคเก่าที่จำกัดความยาวชื่อ)
- มาพร้อมชุดโจทย์ ~**100 SQL questions** บน President DB (เอกสารประกอบ lab)
- บริบท: วิชา Database Systems ป.โท CIS ที่ Assumption University (~ปลาย 90s
  ถึงต้น 2000s) — ผู้เขียนจำได้ว่าน่าจะเชื่อมกับ courseware สาย IBM
- การค้นผิวเว็บ (8 ทาง, 5 ส.ค. 2026): ไม่พบเอกสารต้นทาง; ญาติสาธารณะ
  ใกล้สุด = Juniata College course DB (ADMINVPS/ELECTIONLOSERS)
- **เบาะแสชี้ขาด (ผู้เขียน):** ทั้งชุดมาบนแผ่นดิสก์ 1.44MB เดียว —
